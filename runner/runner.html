Xode on this computer

Let Xode do its work here first: free, and fast, because nothing has to wait for a cloud computer to start.

Off until you turn it on. When it is on, and only while X0 Bot is open, Xode can run its commands (tests, builds, installs) on this computer, for the projects you allow below. Each project is asked about the first time. It works in a folder of its own, from a read-only copy of your code, and cannot see your passwords, keys or other files: commands get a clean environment and a private home folder, and things like sudo, git push, publishing or deleting your home folder are refused. It pauses by itself when the battery is under 20% or Low Power Mode is on. Everything it runs is listed below and kept in a log on this computer for 7 days.

Stop ends what is running and turns this off until you turn it on again.
